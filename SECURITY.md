# Security Policy

## Supported versions

Security fixes are applied to the latest release published on npm. The current line is **3.3.x** (`ai-memory-skill` and the `kiro-memory-skill` forwarder).

## Reporting a vulnerability

Please report security issues privately. Do not open a public GitHub issue, and do not include exploit details in a public discussion.

1. Use GitHub private vulnerability reporting: [Report a vulnerability](https://github.com/syedair/ai-memory-skill/security/advisories/new).
2. Include what is affected (installer, hook, skill, or publish workflow), the impact, and steps to reproduce.
3. If private reporting is unavailable, contact the repository owner on GitHub and wait for a private channel before sharing details.

We will acknowledge the report, investigate, and coordinate a fix before any public disclosure.

## Scope

This policy covers the installer, skills, hooks, and release workflow in this repository. Memory files you create under your own memory folder are outside this project's control.
